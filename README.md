# SubsQ - サブスクリプション管理アプリ

個人向けのサブスクリプション管理Webアプリケーションです。契約中のサービスをカテゴリ別に整理し、多通貨対応で課金総額を把握できます。

## 主な機能

### サブスクリプション管理
- サービス名、プラン名、金額、通貨、課金サイクルを登録
- 次回課金日の管理（期日が近いものは色付きで警告表示）
- 有効/停止のステータス管理
- カテゴリ、支払い方法、請求先、サービスグループによる分類
- テーブル形式の一覧表示（課金額・月額換算・年額換算の3列）
- 複数条件でのフィルタリングとソート
- フィルター状態を新規追加フォームの初期値に反映
- 価格変更予約（変更後の金額と変更予定日を設定、期日になったら「適用」ボタンで反映）

### ダッシュボード
- 月額/年額の合計表示（JPY換算）
- 通貨別の内訳
- カテゴリ別コスト分析（ダッシュボードからサブスク一覧へフィルター連動ナビゲーション）
- サービスグループ別コスト表示
- 価格変更予定セクション（変更予定日の過ぎたものは「適用」ボタン付き警告表示）
- 支払い予定セクション（月額以外の課金サイクルで今月・来月に予定があるもの）

### マスターデータ管理
- **カテゴリ**: カスタムカラー付きで自由に作成、ドラッグ&ドロップで並び替え
- **支払い方法 / 請求先**: 2階層構造（支払い方法 → 請求先）
- **サービスグループ**: 同一プロバイダの複数プランをグルーピング、ドラッグ&ドロップで並び替え
- **為替レート**: 手動入力 + ExchangeRate-APIによる一括更新

### その他
- Replitアカウントによる認証
- iPhone Safari対応（dvh単位、safe-area-inset）
- レスポンシブデザイン（モバイル/デスクトップ）

## 技術スタック

| レイヤー | 技術 |
|----------|------|
| フロントエンド | React, TypeScript, Tailwind CSS, Shadcn UI, wouter |
| バックエンド | Express.js, TypeScript |

## セットアップ

### 必要な環境変数

| 変数名 | 説明 | 必須 |
|--------|------|------|
| `DATABASE_URL` | PostgreSQL接続URL | Yes |
| `ExchangeRate_API_KEY` | ExchangeRate-API.comのAPIキー | No（為替レート自動更新に必要） |

### 起動方法

```bash
npm install
npm run db:push    # データベーススキーマの適用
npm run dev        # 開発サーバー起動（フロント + バック同時）
```

開発サーバーはポート5000で起動します。
