# SubsQ - サブスクリプション管理アプリ

個人向けのサブスクリプション管理Webアプリケーションです。契約中のサービスをカテゴリ別に整理し、多通貨対応で課金総額を把握できます。

## 主な機能

### サブスクリプション管理
- サービス名、プラン名、金額、通貨、課金サイクルを登録
- サービスURL（設定するとサービス名がリンク表示）、請求者名（クレジットカード明細表示名）の管理
- 次回課金日の管理（期日が近いものは色付きで警告表示）
- 有効/停止のステータス管理
- カテゴリ、支払い方法、請求先、サービスグループ、最終請求先による分類
- テーブル形式の一覧表示（課金額・月額換算・年額換算の3列）
- 複数条件でのフィルタリングとソート
- フィルター状態を新規追加フォームの初期値に反映
- 価格変更予約（変更後の金額と変更予定日を設定、期日になったら「適用」ボタンで反映）
- 管理ID（8文字英数字）付与 - 一覧に表示、クリックでクリップボードコピー対応

### ダッシュボード
- 月額/年額の合計表示（JPY換算）
- 通貨別の内訳
- カテゴリ別コスト分析（ダッシュボードからサブスク一覧へフィルター連動ナビゲーション）
- サービスグループ別コスト表示
- 最終請求先別コスト表示（実際の支払い先カード/口座単位での合計）
- 価格変更予定セクション（変更予定日の過ぎたものは「適用」ボタン付き警告表示）
- 今月の実請求予定セクション（月額は常に含む、月額以外は今月のものを表示、コラプシブル）
- 支払い予定セクション（月額以外の課金サイクルで今月・来月に予定があるもの）

### マスターデータ管理
- **カテゴリ**: カスタムカラー付きで自由に作成、ドラッグ&ドロップで並び替え
- **支払い方法 / 請求先**: 2階層構造（支払い方法 → 請求先）
- **最終請求先**: 異なる支払い方法の請求先を同一カード/口座として紐づける独立エンティティ、カスタムカラー付き、ドラッグ&ドロップで並び替え
- **サービスグループ**: 同一プロバイダの複数プランをグルーピング、ドラッグ&ドロップで並び替え
- **為替レート**: 手動入力 + ExchangeRate-APIによる一括更新

### データ管理（`/data`）
- **バックアップ**: 全データ（サブスク・カテゴリ・支払い方法など）をJSONファイルとして保存
- **復元**: バックアップJSONをアップロードして全データを上書き復元（確認ダイアログ付き）
- **CSVエクスポート**: サブスクリプション一覧をBOM付きUTF-8 CSV形式でダウンロード（Excelでも文字化けしない）
- **CSVインポート**: CSVファイルからサブスクリプションを一括追加/更新（ドライランプレビュー → 確認ダイアログ → 実行の3ステップ）。管理IDベースの重複判定（一致・同内容→スキップ、一致・内容変更→更新、不一致→新規作成）

### その他
- ユーザー名/パスワードによる認証（環境変数で設定）
- iPhone Safari対応（dvh単位、safe-area-inset）
- レスポンシブデザイン（モバイル/デスクトップ）

| レイヤー | 技術 |

## セットアップ

### 必要な環境変数

| 変数名 | 説明 | 必須 |
|--------|------|------|
| `DATABASE_URL` | PostgreSQL接続URL | Yes |
| `SESSION_SECRET` | セッション署名用の秘密鍵（長いランダム文字列推奨） | Yes |
| `ADMIN_USERNAME` | ログイン用ユーザー名 | Yes |
| `ADMIN_PASSWORD` | ログイン用パスワード（平文で設定、bcryptでハッシュ化して比較） | Yes |
| `ExchangeRate_API_KEY` | ExchangeRate-API.comのAPIキー | No（為替レート自動更新に必要） |

### 起動方法

```bash
npm install
npm run db:push    # データベーススキーマの適用
npm run dev        # 開発サーバー起動（フロント + バック同時）
```

開発サーバーはポート5000で起動します。
